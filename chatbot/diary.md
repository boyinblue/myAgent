# /diary 명령 가이드

`/diary`는 지정된 날짜에 가장 가까운 포스트를 조회하는 명령입니다.

## 사용법

`/diary (YYYYMMDD)` 또는 `/diary (YYMMDD)` 형식으로 입력합니다.

- `YYYYMMDD`: 4자리 연도 + 2자리 월 + 2자리 일 (예: 20260309)
- `YYMMDD`: 2자리 연도 + 2자리 월 + 2자리 일 (예: 260309)

## 예시

- `/diary 20260309` → 2026년 3월 9일 근처의 포스트 조회
- `/diary 260309` → 26년 3월 9일 (2026-03-09) 근처의 포스트 조회
- `/diary 20250615` → 2025년 6월 15일 근처의 포스트 조회

## 동작

1. 입력된 날짜를 파싱합니다.
2. 아카이브에서 해당 날짜에 **가장 가까운** 포스트를 검색합니다.
3. 포스트의 제목, 미디어, 플랫폼, 출판일, 키워드, URL을 출력합니다.

## 참고

- 정확한 날짜의 포스트가 없으면 가장 가까운 포스트를 반환합니다.
- 거리 차이(며칠 차이)를 함께 표시합니다.
- 포스트가 없으면 오류 메시지를 표시합니다.
