# Dashboard Command Guide

`/dashboard` 명령은 웹 대시보드 제어에 사용합니다.

## Commands
- `/dashboard start` : `tools/web_dashboard_launcher.py launch` 실행
- `/dashboard stop` : `tools/web_dashboard_launcher.py stop` 실행
- `/dashboard status` : `tools/web_dashboard_launcher.py status` 실행

## Notes
- `start`는 대시보드 프로세스를 시작하고 접속 URL 전송을 준비합니다.
- `stop`은 실행 중 대시보드를 종료합니다.
- `status`는 대시보드 실행 상태(PID 포함)를 확인합니다.
