# Post Command Guide

`/post` 명령으로 아카이브 포스트를 입력/검색/검증할 수 있습니다.

## Commands
- `/post <URL>`
  - GitHub Action `run_crowler.yml`을 `workflow_dispatch`로 실행합니다.
- `/post search <키워드>`
  - 해당 키워드를 포함하는 포스트 목록을 조회합니다.
- `/post validate`
  - 포스트 무결성 검사를 수행합니다.

## Examples
- `/post https://blog.naver.com/아이디/포스트번호`
- `/post search 와인`
- `/post validate`
