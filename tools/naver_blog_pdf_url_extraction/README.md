# 네이버 블로그 PDF URL 추출

이 디렉터리에 넣은 네이버 블로그 PDF에서 네이버 블로그 URL을 추출합니다. 월별 글 수는 `boyinblue` 계정의 게시글 URL 중 날짜를 하나로 판별할 수 있는 항목을 집계합니다.

## 실행 방법

Python 3.10 이상과 `pypdf`가 필요합니다.

```powershell
python -m pip install pypdf
python extract_naver_blog_urls.py
```

스크립트는 현재 디렉터리의 PDF 전체를 읽어 `blog_urls.csv`와 이 README를 갱신합니다. CSV에는 추출한 전체 네이버 블로그 URL, 블로그 ID, 게시글 여부, 날짜 판별 상태, 원본 PDF 파일명, 페이지 번호가 포함됩니다. `date_status`가 `ambiguous` 또는 `undated`인 소유자 게시글은 월별 집계에서 제외됩니다.

## 처리 결과

- PDF 파일: 36개
- 검사한 페이지: 34,005페이지
- URL이 포함된 페이지: 1,776페이지
- 중복 제거한 전체 블로그 URL: 1,778개
- `boyinblue` 게시글 URL: 1,734개
- 날짜를 하나로 판별한 소유자 게시글: 1,730개
- 날짜가 없거나 여러 날짜로 판별된 소유자 게시글: 4개 (날짜 없음 0, 날짜 모호 4)
- 지정한 집계 범위 밖의 날짜: 0개
- 집계 기간: 2014년 1월~2026년 12월

월별 0건은 현재 폴더의 PDF에서 해당 월로 판별된 글이 없다는 뜻이며, 그 달에 블로그 글이 없었다는 뜻은 아닙니다.
