# 네이버 블로그 PDF URL 추출

이 디렉터리에 넣은 네이버 블로그 PDF에서 네이버 블로그 URL을 추출합니다. 월별 글 수는 `boyinblue` 계정의 게시글 URL 중 날짜를 하나로 판별할 수 있는 항목을 집계합니다.

## 실행 방법

Python 3.10 이상과 `pypdf`가 필요합니다.

```powershell
python -m pip install pypdf
python extract_naver_blog_urls.py
python crawl_uncrawled_urls.py
```

스크립트는 현재 디렉터리의 PDF 전체를 읽어 `blog_urls.csv`와 이 README를 갱신합니다. CSV에는 추출한 전체 네이버 블로그 URL, 블로그 ID, 게시글 여부, 날짜 판별 상태, 원본 PDF 파일명, 페이지 번호가 포함됩니다. `date_status`가 `ambiguous` 또는 `undated`인 소유자 게시글은 월별 집계에서 제외됩니다.
`crawl_uncrawled_urls.py`는 CSV의 `boyinblue` 게시글 중 프로젝트 아카이브에 없는 URL만 기존 네이버 크롤러로 가져옵니다. robots.txt 정책을 따르며, 결과는 `crawl_results.csv`에 기록합니다. 아카이브 DB를 진행 상태로 사용하므로 중단 후 다시 실행해도 이미 수집된 글은 건너뜁니다.

## 처리 결과

- PDF 파일: 44개
- 검사한 페이지: 36,445페이지
- URL이 포함된 페이지: 2,074페이지
- 중복 제거한 전체 블로그 URL: 2,082개
- `boyinblue` 게시글 URL: 2,022개
- 날짜를 하나로 판별한 소유자 게시글: 2,018개
- 날짜가 없거나 여러 날짜로 판별된 소유자 게시글: 4개 (날짜 없음 0, 날짜 모호 4)
- 지정한 집계 범위 밖의 날짜: 0개
- 집계 기간: 2014년 1월~2026년 12월

월별 빈칸은 현재 폴더의 PDF에서 해당 월로 판별된 글이 없다는 뜻이며, 그 달에 블로그 글이 없었다는 뜻은 아닙니다.
